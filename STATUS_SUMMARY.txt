================================================================================
                            QUICK START (5 MIN)
================================================================================

1. INSTALL DEPENDENCIES:
   cd backend && npm install
   cd ../frontend && npm install

2. CONFIGURE ENVIRONMENT:
   Create backend/.env with:
   DATABASE_URL=postgresql://user:password@localhost:5432/provakil
   PORT=4000
   CORS_ORIGIN=http://localhost:3000

3. INITIALIZE DATABASE:
   cd backend && npm run migrate

4. START SERVICES (2 TERMINALS):
   Terminal 1: cd backend && npm run dev
   Terminal 2: cd frontend && npm run dev

5. OPEN BROWSER:
   http://localhost:3000

6. TEST CASE LOOKUP:
   Select court from dropdown (29 options)
   Enter case number (e.g., W.P.(C)-5972/2022)
   Click "Look Up Case"
   Case will route to selected court adapter

CASE LOOKUP (all 29 courts):

  {
    "case_no": "W.P.(C)-5972/2022",
    "court_id": "delhi_hc",      // Change to any of 29 courts
    "client_id": "optional-uuid"
  }

GET CASE DETAILS:
  GET /cases/:id
  Returns: case, parties, hearings, billing

SEARCH GLOBALLY:
  GET /search?q=case+number

MANAGE CLIENTS:
  POST /clients
  GET /clients
  GET /clients/:id

CREATE BILLING ENTRIES:
  POST /billing/entries

SEND NOTIFICATIONS:
